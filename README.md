# Бібліотека гутірок

Інтерактивні гутірки для пластового юнацтва: для сходин гуртка і таборів.

- Сайт: https://gutirky-fi.github.io/
- Пульт для телефона: https://gutirky-fi.github.io/pult/

## Як влаштовано

- `index.html` — бібліотека, каталог вмілостей і всі гутірки (зараз: «Кераміка України», повна і вишкіл). Збирається з папки `_robota/`.
- `pult/index.html` — сторінка пульта. На неї веде QR-код з кнопки «📱 Пульт» у гутірці.
- `_robota/` — робочі файли, з яких збирається сайт, і повний опис проєкту (`_robota/PROEKT.md`).
- Сайт прихований від пошукових систем (`robots.txt`, `noindex`).

Оновлення вносить Claude: після змін сторінка оновлюється через 1–2 хвилини (Ctrl+F5 у Chrome).
