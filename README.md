# Бібліотека гутірок

Інтерактивні гутірки для сходин, таборів і вишколів.

- Сайт: https://gutirky-fi.github.io/
- Пульт для телефона: https://gutirky-fi.github.io/pult/

## Як влаштовано

- `index.html` — бібліотека і всі гутірки (зараз: «Кераміка України», повна і вишкіл).
- `pult/index.html` — сторінка пульта. На неї веде QR-код з кнопки «📱 Пульт» у гутірці.
- Сайт прихований від пошукових систем (`robots.txt`, `noindex`).

Оновлення вносить Claude: після змін сторінка оновлюється через 1–2 хвилини (Ctrl+F5 у Chrome).
