# Проєкти (реєстр для старту розмови «Пласт»)

Кожен рядок — один проєкт. Навичка `plast-start` показує їх кнопками + «Новий проєкт».
Новий проєкт додається сюди одразу, як власник погодить його будову.

| Проєкт | Де лежить | Що це | Стан |
|---|---|---|---|
| Пластова бібліотека | репозиторій `gutirky-fi/gutirky-fi.github.io`, памʼятка `_robota/PROEKT.md` | сайт гутірок, ігри, пульт, друк, кіно-гутірки | працює, https://gutirky-fi.github.io |
| Хода звіздарів | ще не створено (план у власника) | новий проєкт на механіці бібліотеки | чекає плану |
| Документація гуртка | розділ «Документи» бібліотеки; памʼятка `_robota/dokumenty/PROEKT.md` | жива книга гуртка: форми для діловодів → Google Таблиця виховника → звіти для друку; відкритий бланк для всіх (друк, PDF, Word) | Етапи 1–2 зроблено (каталог; книга XLSX + приймач); далі Етап 3 — сторінки сайту |
| Лаунчер проєктора HY300 | приватний репозиторій `gutirky-fi/hy300-launcher`, памʼятка `HANDOFF.md` (читати лише її) | власний головний екран проєктора в стилі Пласту: плитки, HDMI, Медіатека, бібліотека на весь екран | працює; 9.11 — велике оновлення (бібліотека на весь екран, HDMI напряму + «Назад» на пластовий екран, нові значки, напівпрозорі плитки, заставки); 9.11 вечір — оновлення через інтернет (полиця `prohramy`); остання ручна установка — збірка №38, далі проєктор оновлюється сам |
| Полиця програм | публічний репозиторій `gutirky-fi/prohramy` (README) | лише готові файли програм для автооновлення (зараз — лаунчер HY300); без коду й даних сайту | працює; файли кладе Claude скриптом програми |

## Механіка, яку новий проєкт може взяти з бібліотеки
Сайт на GitHub Pages, схований від пошуку (noindex + robots.txt); збирання з джерел у `_robota/` скриптами `zibraty.py`; пульт з телефона через QR (`_robota/src/pult_ihry.py`, `pult/`); ігри СКОБ, Змаг, Бінго, Опитування з «Репетицією»; друк (A4, картки, памʼятки); кіно-гутірки (GSAP: переліт, пірнання, текст із розмиття); родина дизайну (`_robota/RODYNA.md`); памʼятки CLAUDE.md / PROEKT.md / ZHURNAL.md / YAK-PRATSIUVATY.md; перевірка й знімки `_robota/perevirka/ihry/`.
