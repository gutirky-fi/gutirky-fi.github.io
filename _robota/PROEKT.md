## 3. Як влаштована сторінка

Один файл `index.html`, три «види» (показується один):

- `#lib` — **бібліотека**: вкладки «Гутірки» і «Каталог вмілостей» (адреса `#katalog`).
- `#gv` — **гутірка** (відкривається кнопками «Повна гутірка» / «Вишкіл»; адреси `#povna`, `#vyshkil`).
- `#pv` — **пульт на телефоні** (коли сторінку відкрили з QR-коду `?c=КОД&k=КЛЮЧ` або з `#pult`).

Код гутірки загорнутий у `startGutirka(MODE, TOKEN)`; неактивні екземпляри не реагують на події (`window.__alive`).
Кутове меню гутірки (`#corner` / `#hot` / `#cmenu`) — правий верхній кут: Зміст, Пульт, На весь екран, Бібліотека.
На мишці відкривається наведенням, на дотику — натисканням (клас `touchmode` на body). Стрілок «назад/далі» і країв для гортання немає — власник їх прибрав.

### Пульт (телефон керує гутіркою на ноутбуці)
- PeerJS 1.5.5 з cdnjs (запасні: jsdelivr, unpkg); id ноутбука `gutirka-<6 цифр>`.
- QR-код веде на `https://gutirky-fi.github.io/pult/?c=КОД&k=КЛЮЧ`; з ключем підтвердження не потрібне.
  Ручне введення коду → на ноутбуці питання «Це ваш телефон?» → «Дозволити».
- Повідомлення (v:1): hello / welcome / wait / deny / state / ping / pong / cmd (`from` — індекс слайда, щоб відкидати застарілі команди); стан `idle`, коли відкрита бібліотека; heartbeat, автоперепідключення, wake lock.
- Потрібен інтернет на обох пристроях; сама гутірка працює й без інтернету.
- **Не ламати сумісність** протоколу між `pult/index.html`, `#pv` і `pult-host-file.js`.

```bash

gh api repos/gutirky-fi/gutirky-fi.github.io/actions/runs --jq '.workflow_runs[0] | "\(.head_sha[0:7]) \(.status) \(.conclusion)"'
```
Після публікації (1–2 хв) власник оновлює сторінку: на ноутбуці Ctrl+F5, на телефоні — потягнути сторінку вниз.

`build.py`: змінні `PREVIEW=1` (смужка «попередній перегляд» — для копії в Claude), `SHELL_NAME=shell_file` (старий дизайн), `OUT=...`, `PULT_URL=...`, `NOINDEX=0`.
Що робить збірка в дизайні Д1: стилі = `shell_file.css` без правил `#lib` + `lib_d1.css` + `gutirka_d1.css`; у `shell_file.js` блок «бібліотека» замінюється на `lib_d1.js`, спереду — `skills_data.js`;
меню в куті отримує емблему і значки замість емодзі; у «Змісті» кольори регіонів — кружечками; вікно пульта — з емблемою;
картинки вбудовуються як data URI (`{{LOGO}}`, `{{EMBLEM}}`, `{{KERAMIKA_MAP}}`); значки вкладки — емблема.

Копію для показу в Claude (артефакт) збирати з `PREVIEW=1`; в артефакті не працює пульт (WebRTC заборонено) і не видно нашивок (зовнішні картинки заборонено).
Шрифти Google і plast.global у середовищі Claude недоступні — для знімків екрана шрифти можна взяти з github.com/google/fonts (git sparse-checkout), а нашивки підмінити тестовими.
