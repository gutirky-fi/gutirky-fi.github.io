## 1. Хто, що і навіщо

- **Власник:** пластовий виховник у Гельсінкі (Пласт — Українська скаутська організація в Фінляндії). Працює з **юнацтвом** (УПЮ, 12–17 років). Пише українською, часто голосом (у тексті бувають помилки розпізнавання — розуміти за змістом).
- **Не програміст.** Потрібні прості покрокові пояснення, готові посилання, мінімум технічних слів. Ноутбук (Windows, Chrome) і телефон (Android, Chrome).
- **Мета:** бібліотека інтерактивних гутірок для сходин гуртка і таборів, яку ведуть з ноутбука на проектор, а гортають з телефона (пульт). Гутірки бувають «до вмілостей» (готують до пластових вмілостей) і «пізнавальні».
- **Як почалося (зі слів власника):** завдання для вишколу (відбудеться **24.10.2026 у Швеції**; план здати до 20.10) — гутірка на будь-яку тему до 20 хв (ідеї: скелелазіння, кераміка, зовнішня реклама). 11.10.2026 друг із Пласту показав презентацію, зроблену з Claude. 13.10 перша спроба в ChatGPT не вдалась → реєстрація в Claude (спершу безкоштовно) → «Кераміка України» (версія з картою всіх областей — з Claude). Далі: два файли (повна/вишкіл) → «програвач»-бібліотека (кілька переробок) → каталог вмілостей. Пульт: спершу довгий код, що не працював → ідея окремого QR-додатка відпала → універсальний пульт (QR + 6 цифр) для всіх гутірок. Вступ на сторінці історії — `_robota/istoriya/korotko.txt`.
- **Сайт поки неофіційний і прихований:** власник робить його «втихаря». Сайт не індексується (див. нижче).

## 3. Як влаштована сторінка

Один файл `index.html`, три «види» (показується один):

- `#lib` — **бібліотека**: вкладки «Гутірки» і «Каталог вмілостей» (адреса `#katalog`).
- `#gv` — **гутірка** (відкривається кнопками «Повна гутірка» / «Вишкіл»; адреси `#povna`, `#vyshkil`).
- `#pv` — **пульт на телефоні** (коли сторінку відкрили з QR-коду `?c=КОД&k=КЛЮЧ` або з `#pult`).

Код гутірки загорнутий у `startGutirka(MODE, TOKEN)`; неактивні екземпляри не реагують на події (`window.__alive`).
Кутове меню гутірки (`#corner` / `#hot` / `#cmenu`) — правий верхній кут: Зміст, Пульт, На весь екран, Бібліотека.
На мишці відкривається наведенням, на дотику — натисканням (клас `touchmode` на body). Стрілок «назад/далі» і країв для гортання немає — власник їх прибрав.

### Пульт (телефон керує гутіркою на ноутбуці)
- PeerJS 1.5.5 з cdnjs (запасні: jsdelivr, unpkg); id ноутбука `gutirka-<6 цифр>`.
- QR-код веде на `https://gutirky-fi.github.io/pult/?c=КОД&k=КЛЮЧ`; з ключем підтвердження не потрібне.
  Ручне введення коду → на ноутбуці питання «Це ваш телефон?» → «Дозволити».
- Повідомлення (v:1): hello / welcome / wait / deny / state / ping / pong / cmd (`from` — індекс слайда, щоб відкидати застарілі команди); стан `idle`, коли відкрита бібліотека; heartbeat, автоперепідключення, wake lock.
- Потрібен інтернет на обох пристроях; сама гутірка працює й без інтернету.
- **Не ламати сумісність** протоколу між `pult/index.html`, `#pv` і `pult-host-file.js`.

## 4. Збирання, перевірка, публікація

```bash
cd gutirky-fi.github.io
python3 _robota/vmilosti/zibraty_katalog.py   # лише якщо змінювали дані каталогу
python3 _robota/build.py                      # -> index.html (дизайн Д1, з noindex)
python3 _robota/perevirka/perevirka.py        # має закінчитись «УСЕ ГАРАЗД»
python3 _robota/perevirka/ekrany.py           # (за потреби) 20 екранів: телефони, планшети, ноутбуки, 4K; спершу python3 -m http.server 8765 --bind 127.0.0.1 у корені
python3 _robota/istoriya/zibraty.py           # сторінка історії (після помітних змін — спершу додати подію в podii.json)
git add -A && git commit -m "..." && git push origin HEAD:main
gh api repos/gutirky-fi/gutirky-fi.github.io/actions/runs --jq '.workflow_runs[0] | "\(.head_sha[0:7]) \(.status) \(.conclusion)"'
```
Після публікації (1–2 хв) власник оновлює сторінку: на ноутбуці Ctrl+F5, на телефоні — потягнути сторінку вниз.

`build.py`: змінні `PREVIEW=1` (смужка «попередній перегляд» — для копії в Claude), `SHELL_NAME=shell_file` (старий дизайн), `OUT=...`, `PULT_URL=...`, `NOINDEX=0`.
Що робить збірка в дизайні Д1: стилі = `shell_file.css` без правил `#lib` + `lib_d1.css` + `gutirka_d1.css`; у `shell_file.js` блок «бібліотека» замінюється на `lib_d1.js`, спереду — `skills_data.js`;
меню в куті отримує емблему і значки замість емодзі; у «Змісті» кольори регіонів — кружечками; вікно пульта — з емблемою;
картинки вбудовуються як data URI (`{{LOGO}}`, `{{EMBLEM}}`, `{{KERAMIKA_MAP}}`); значки вкладки — емблема.

Копію для показу в Claude (артефакт) збирати з `PREVIEW=1`; в артефакті не працює пульт (WebRTC заборонено) і не видно нашивок (зовнішні картинки заборонено).
Шрифти Google і plast.global у середовищі Claude недоступні — для знімків екрана шрифти можна взяти з github.com/google/fonts (git sparse-checkout), а нашивки підмінити тестовими.

3. «Вишкіл» — це **його власна** коротка версія гутірки для себе (підпис «Виховники, малі групи»). Сайт не називати «для вишколів». «Повна гутірка» — для юнацтва («Юнацтво, 12–17 років»).
4. **Не обіцяти** регулярних нових гутірок («щотижня» тощо) у текстах сайту.
5. У кожної гутірки своя картинка в блоці «Остання гутірка».
6. Каталог вмілостей — з **plast-finland.com/vmilosti** (портал Пласту у Фінляндії, який бере дані з plast.global). Посилання рівнів ведуть на plast-finland.com. Підпис джерела: «Перелік вмілостей і нашивки взято з каталогу вмілостей Пласту у Фінляндії, а той бере їх із бібліотеки вмілостей Пласту».
7. Нашивки — офіційні картинки з plast.global, **не перефарбовувати** (щоб збігались з офіційними сайтами). Чорно-білі (вмілості Пласту в Польщі) — на світлій круглій підкладці; «Настільні ігри» (PNG з білим фоном) — обрізані по колу. Позначок «Польща» не додавати. У каталозі (і в кожній спеціалізації) чорно-білі й без нашивки — **у самому кінці** (порядок: з гутірками → кольорові → «Настільні ігри» (PNG з білим фоном) і «Сигналізація-комунікація» → чорно-білі → без нашивки).
8. Майбутнє: коли з'являться матеріали для новацтва чи пташат — верхній надпис «Пласт у Фінляндії» і фільтр за уладом (Пташата / Новацтво / Юнацтво).
9. Сайт прихований (noindex + robots.txt) — не прибирати без прохання.

## 9. Як додати нову гутірку (зараз)

«Кераміка» вбудована в сам `index.html` (`gutirky/keramika/index.html`, режими full/short, `startGutirka`).
**Нові гутірки — окремою сторінкою сайту** (так зроблено «Будова літальних апаратів І», 14.10.2026):
1. Тека `_robota/gutirky/<назва>/` зі своїм `index.html` (+ дані) і збирачем `zibraty.py` → `gutirky/<назва>/index.html` на сайті (усе в одному файлі).
   Меню в куті, пульт (`src/pult-host-file.js` + `window.GUTIRKA`), гра «Потужний СКОБ!» (`src/skob.js`) — підключаються в самій сторінці.
2. Запис у `BUILTIN` (`src/shell_file.js`) з `vars: [{ href: 'gutirky/<назва>/#hutirka', … }]` (замість `mode`); `yun: true` — матеріал для юнацтва (не рахується як версія).
3. У `src/lib_d1.js` — `type`, `skill`, `added`, `art` (картинка в `src/img/`, вставляється через `{{…}}` у `build.py`), `short`, і точки вимог у `DETAILS`.
4. Поки власник не погодив — у записі `proba: true`: гутірка видна лише в копії для показу (`PREVIEW=1`). Після згоди — прибрати `proba: true`, зібрати сайт.
Копія для показу: `mkdir -p proba/sait && OUT=proba/sait/index.html PREVIEW=1 python3 _robota/build.py && python3 _robota/gutirky/budova-la-1/zibraty.py sait proba/sait`.
Справжній сайт (після згоди): прибрати `proba: true` → `python3 _robota/build.py && python3 _robota/gutirky/budova-la-1/zibraty.py sait .`
Картинку для блоку «Остання гутірка» робити з самої гутірки.
